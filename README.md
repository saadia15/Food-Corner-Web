# Food-Corner-Web
# Food Corner 🍴
Food Corner is a modern and responsive restaurant website created as part of a CSS Lab project. The website is designed with a clean, professional restaurant theme and focuses on applying CSS concepts in a practical and attractive way.

# About the Project
The website represents a fictional restaurant called Food Corner, offering a simple and user-friendly interface for visitors. It includes a welcoming home page along with Menu, About, and Contact views. The navigation allows users to move between these views without leaving the main page.
The project demonstrates the use of HTML, CSS, and basic JavaScript navigation while keeping the overall design simple, clean, and professional.

# Features
. Professional restaurant-style design

# Project Purpose
The main purpose of this project is to demonstrate how different CSS properties and concepts can be combined to create a visually appealing and responsive website instead of using CSS concepts only in isolated examples.
